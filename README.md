## What I've built

Most of my work is written up as case studies rather than published as code, because it was built inside companies. The short version:

- **An MCP server over live production data.** Read-only, permission-scoped per Google Workspace group, every statement wrapped in a READ ONLY transaction. Support answers "where is this payment" without an engineer.
- **Agent guardrails for systems that move money.** A deny-by-default safety model that let an agent operate live payment and fraud products, with destructive actions blocked at four separate call sites and exceptions human-vetted.
- **Support tickets as a product signal.** Every ticket classified and clustered into persistent issues, scored on recurrence and on how many distinct clients each one hits, so a noisy merchant is separable from a real defect.
- **off-script.** A solo AI product, zero to live in about twelve days. 137 sources, orchestration, local model enrichment, a Telegram bot and an operator dashboard I rebuilt after admitting the first one was unreadable.
- **rubric-evals.** An eval harness for an idea-scoring pipeline that had quietly stopped being able to say yes. The rubric turned out to be the thing under test.

Full write-ups are in progress, including what each one turned out to be about.
